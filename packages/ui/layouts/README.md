# Layouts (L4)

Structural containers / surfaces that compose lower layers (atoms, components,
compounds): e.g. `dock`, `sheet`, `overlay`, `stack`.

Add a layout as `{name}/{name}.css` + `{name}.js`, register it in
`library.manifest.json` (`styles[]` + `factories`), and compose only L0–L3.
See the [Design Spec](../../../docs/design-library/design-spec.md) (LG-P3).
