# Examples

Small consumer-facing examples for the liquid-glass packages. Larger internal
apps live in [`../apps`](../apps).

| Example | Stack | Run |
| --- | --- | --- |
| [`vanilla/`](./vanilla/index.html) | Plain HTML + ESM | Serve via any bundler/dev server that resolves `@liquid-glass/core`, or build the core package and repoint the import to its `dist/index.js`. |

The public Design Library is in [`../docs`](../docs). The interactive
engine playground is in [`../apps/playground`](../apps/playground).
